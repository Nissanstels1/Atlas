# Atlas for OpenWrt 24.10.1+

[Atlas 0.25 beta — packages and source](https://github.com/Nissanstels1/Atlas/releases/tag/v0.25.0-beta)

Исправлены три недостатка повторного аудита 0.24:

- Свежесть замеров расширенного автовыбора оценивается по собственному интервалу секции. Проверены как длинный, так и короткий интервал относительно общего.
- Ошибка переключения отдельной группы не прерывает остальные. Диагностика сохраняет частичный результат, последний известный выбранный и запрошенный выходы неудачной группы.
- Проверка задержек секции охватывает все 1024 сервера максимального пула без пропуска последних двух. Большой пул с недоступными серверами может проверяться долго: запросы выполняются последовательно.

297 автоматических сценариев: Linux с sing-box 1.12.17 — 286 успешно, 11 пропущено; Windows — 282 успешно, 15 пропущено. В OpenWrt 25.12.0 / sing-box 1.13.21 повторены три исправленных случая с моделью контроллера и проверены реальные группы, конфигурация, запуск/остановка и восстановление WAN: 21 синтетическое событие, один работник и один перезапуск, API движка доступен. Проверка максимального пула использует модель ответов, а не 1024 реальных соединения.

IPK для OpenWrt 24.10 / opkg, APK для OpenWrt с apk. APK собран официальным apk-tools из SDK; установщик проверяет SHA256 и использует allow-untrusted для пакета Atlas, поскольку публичной подписи репозитория нет.

Полное превосходство над Podkop не подтверждено: нужны физические сравнительные испытания скорости, RAM и длительной стабильности. Сохраняются ограничения резервной копии 16 МиБ, RPC, удалённых профилей и detour между независимыми секциями. В архиве — docs/release-0.25.md и воспроизводимые тесты. GitHub Releases и raw-зеркало принадлежат одному провайдеру.
