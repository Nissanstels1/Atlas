# Atlas для OpenWrt

Секции объединяют подключение, профили, домены, IP и списки. Каждая секция может независимо выбирать сервер из всех или нескольких подписок. Для начала откройте мастер «Настроить по вопросам».

## Установка и обновление одной командой

Выполните в терминале роутера под root:

```sh
wget -O /tmp/atlas-install.sh https://raw.githubusercontent.com/Nissanstels1/Atlas/main/install.sh && sh /tmp/atlas-install.sh
```

Команда устанавливает Atlas 0.29.0 и автоматически применяет актуальные проверенные исправления из закреплённого коммита. Отдельную команду repair запускать не нужно. Для обновления существующей установки выполните ту же команду повторно; настройки сохраняются. Фоновое автоматическое обновление приложения не включается.

После установки откройте LuCI → Службы → Atlas. После обновления перезагрузите страницу сочетанием Ctrl+F5. Прокси начнёт обслуживать выбранные сайты после настройки и применения правил.

Поддерживаются стабильные OpenWrt 24.10.1 и новее, ARM64/aarch64_generic и x86_64. Нужен интернет и рабочие feeds вашей прошивки. Установщик выбирает IPK/opkg или APK/apk, проверяет SHA-256, устанавливает зависимости и отдельный Atlas Engine r3. APK не подписаны публичным ключом: bootstrap явно разрешает их после проверки SHA-256.

## Последние изменения

- В списке по умолчанию видны только профили, прошедшие фильтры. Выделенная плашка сообщает число скрытых; «Показать все профили» возвращает их для просмотра.
- Несколько исключений по названию: LTE, RUS. Исключается любое совпадение без учёта регистра; фильтры ограничивают подписочные пулы секций.
- Исправлены запросы HTTPS/SVCB при FakeIP, повторный разбор конфигурации локального API и счётчик памяти движка.
- Сохранены независимый автовыбор секций из нескольких подписок, каталог пользовательских списков, пояснения и адаптивный интерфейс.

[Описание последних изменений и границы проверки](atlas-openwrt/docs/updates-2026-10-17.md) · [Исходники приложения](atlas-openwrt) · [Базовые пакеты 0.29.0](https://github.com/Nissanstels1/Atlas/releases/tag/v0.29.0-beta).

Пакеты и архив исходного релиза 0.29.0 являются базовой сборкой. Чтобы получить все исправления, используйте команду выше: она автоматически завершает обновление. Локальные отчёты роутера, настройки, подписки и ключи доступа не распространяются.

Серверная версия проверена 507 тестами на виртуальной OpenWrt: ошибок нет, один пропуск. В браузере проверены меню и адаптивность на 12 размерах экрана. Полная анонимность и превосходство по всем показателям над Podkop не заявляются.
