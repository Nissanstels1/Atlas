# Atlas для OpenWrt

Секции объединяют подключение, профили, домены, IP и списки. Каждая секция может независимо выбирать сервер из всех или нескольких подписок. Для начала откройте мастер «Настроить по вопросам».

## Установка и обновление одной командой

Выполните в терминале роутера под root:

```sh
wget -O /tmp/atlas-install.sh https://raw.githubusercontent.com/Nissanstels1/Atlas/main/install.sh && sh /tmp/atlas-install.sh
```

Команда устанавливает Atlas 0.29.0 и автоматически применяет актуальные проверенные исправления из закреплённого коммита. Отдельную команду repair запускать не нужно. Для обновления существующей установки выполните ту же команду повторно; настройки сохраняются. Фоновое автоматическое обновление приложения не включается.

После установки откройте LuCI → Службы → Atlas. После обновления перезагрузите страницу сочетанием Ctrl+F5. Прокси начнёт обслуживать выбранные сайты после настройки и применения правил.

Поддерживаются стабильные OpenWrt 24.10.1 и новее, ARM64/aarch64_generic и x86_64. Нужен интернет и рабочие feeds вашей прошивки. Установщик выбирает IPK/opkg или APK/apk, проверяет SHA-256, устанавливает зависимости и отдельный Atlas Engine r3. APK не подписаны публичным ключом: bootstrap явно разрешает их после проверки SHA-256.

## Последние изменения

- В подписке поддерживается до 2048 профилей; проверка крупных источников выполняется частями. Новая подписка более чем на 512 профилей сохраняется без автоматического перезапуска: сначала настройте фильтры и примените изменения. У каждой подписки есть свой фильтр стран и исключений по названию. Страна берётся из названия провайдера или последней проверки выхода и не является гарантией местоположения.
- Дополнительный режим «FakeIP и DoH для прямых сайтов» выключен по умолчанию. Для явных прямых исключений он использует FakeIP и зашифрованный DNS без прокси; DNS-сервис видит их названия и внешний IP пользователя. Адреса, маршрут которых может зависеть от IP-списков, проверяются через прокси и могут ждать при его недоступности. Режим требует включённого FakeIP и DNS через HTTPS; блокировка QUIC в этом режиме пока не поддерживается. Существующие правила и настройки при обновлении сохраняются.
- Режим «Резервный DNS при сбое прокси» тоже выключен по умолчанию. Если прокси недоступен, защищённые DNS-запросы временно отправляются напрямую через DoH; DNS-сервис может увидеть внешний IP и запрашиваемые имена. Правила маршрутизации трафика остаются прежними. При зависшем сервере обнаружение отказа может занять десятки секунд. Требуются DoH и движок с `urltest.fallbacks` и `urltest.background`.
- Дополнительный режим «Если сайт не открылся» выключен по умолчанию. В режиме «По правилам» после повторных зафиксированных ошибок прямого HTTPS-соединения Atlas проверяет домен через выбранный прокси с помощью DoH и TLS с проверкой сертификата. При успехе точный домен отправляется через прокси на час; правило можно убрать или сохранить в секцию. Первое соединение остаётся прямым; сайт может потребовать обновления страницы. Поддерживается IPv4; ошибки DNS, HTTP-блокировки и обрывы после установления соединения могут не определяться. Явные прямые исключения сохраняются; при неоднозначных исключениях по устройствам или активных прямых/блокирующих списках проверка приостанавливается. При отсутствии прокси прямой трафик не меняется. Для сопоставления домена и ошибки движок обрабатывает подробные диагностические события, что может повысить нагрузку; при обычном уровне журнала такие события не сохраняются в системный журнал.

- Кнопка «В секцию» в мониторе соединений: сайт с поддоменами, редактирование и удаление назначенных адресов. [Описание и проверка](atlas-openwrt/docs/updates-2026-10-24.md).

- Компактные соединения, плотные карточки всех экранов, подсветка активного профиля и отдельный раздел «Мои списки». [Подробнее](atlas-openwrt/docs/updates-2026-10-18.md).

- Компактный обзор: все подписки доступны прокруткой, автозапуск — одна кнопка, ссылки видимы и переносятся вниз. [Изменения интерфейса](atlas-openwrt/docs/updates-2026-10-18.md).

- В списке по умолчанию видны только профили, прошедшие фильтры. Выделенная плашка сообщает число скрытых; «Показать все профили» возвращает их для просмотра.
- Несколько исключений по названию: LTE, RUS. Исключается любое совпадение без учёта регистра; фильтры ограничивают подписочные пулы секций.
- Исправлены запросы HTTPS/SVCB при FakeIP, повторный разбор конфигурации локального API и счётчик памяти движка.
- Сохранены независимый автовыбор секций из нескольких подписок, каталог пользовательских списков, пояснения и адаптивный интерфейс.

[Описание последних изменений и границы проверки](atlas-openwrt/docs/updates-2026-10-17.md) · [Исходники приложения](atlas-openwrt) · [Базовые пакеты 0.29.0](https://github.com/Nissanstels1/Atlas/releases/tag/v0.29.0-beta).

Пакеты и архив исходного релиза 0.29.0 являются базовой сборкой. Чтобы получить все исправления, используйте команду выше: она автоматически завершает обновление. Локальные отчёты роутера, настройки, подписки и ключи доступа не распространяются.

Серверная версия проверена 530 тестами на виртуальной OpenWrt: ошибок нет, один пропуск. В браузере проверены меню и адаптивность на 12 размерах экрана. Полная анонимность и превосходство по всем показателям над Podkop не заявляются.

Установка проверена на отдельной виртуальной OpenWrt с загрузкой файлов с GitHub: все 14 файлов исправления совпали по SHA-256, настройки и резервная копия сохранились, RPC зарегистрирован, новый вид LuCI загрузился с авторизацией.
