# Atlas for OpenWrt 24.10.1+

[Atlas 0.24 beta — packages and source](https://github.com/Nissanstels1/Atlas/releases/tag/v0.24.0-beta)

Исправлены пять недостатков повторного аудита 0.23:

- Пустой пул при включённых списках даёт понятную ошибку вместо KeyError.
- Экспертный URLTest с дочерним тегом control получает уникальный selector без повреждения графа.
- Планировщик и обработчик WAN сериализованы: одно событие не вызывает два параллельных перезапуска.
- Серия WAN-событий обслуживается одним работником, который получает блокировку ещё при запуске и обрабатывает последнее событие.
- UDP-over-TCP и версия задаются отдельно для обычной SOCKS/Shadowsocks секции; независимые копии выходов сохраняют ручной и автоматический выбор, фильтры и имена серверов.

294 автоматических сценария: Linux с sing-box 1.12.17 — 283 успешно, 11 пропущено; Windows — 279 успешно, 15 пропущено. Chrome: новые поля, прежние сценарии и мобильная ширина прошли (RPC заменён тестовой моделью). OpenWrt 25.12.0 / sing-box 1.13.21: независимые группы и настройки UDP-over-TCP, запуск/остановка, 21 синтетическое событие WAN при дополнительном вызове планировщика — один обработчик и один перезапуск, API движка доступен после восстановления. Трафик до внешнего UDP-over-TCP сервера не испытан.

Полное превосходство над Podkop по всем параметрам не доказано: нужны физические сравнительные испытания скорости, RAM и длительной стабильности. Остаются ограничения резервной копии 16 МиБ, RPC, удалённых профилей и detour между независимыми секциями. Подробности и воспроизводимые тесты находятся в архиве исходников, docs/release-0.24.md.

IPK для OpenWrt 24.10 / opkg, APK для OpenWrt с apk. APK не подписан публичным ключом: установщик проверяет SHA256 и использует allow-untrusted для пакета Atlas. GitHub Releases и raw-зеркало — два адреса одного провайдера.
