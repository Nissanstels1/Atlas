# Atlas for OpenWrt 24.10.1+

[Atlas 0.26 beta — packages and source](https://github.com/Nissanstels1/Atlas/releases/tag/v0.26.0-beta)

Добавлены возможности для устранения функциональных ограничений предыдущей сверки:

- Экспертные detour/outbounds/default могут ссылаться на другие секции, существующие группы, пулы и профили. Локальные теги изолированы; общий граф проверяется на отсутствующие/выключенные выходы и циклы. В OpenWrt выполнена реальная локальная передача HTTP-запроса через SOCKS и HTTP-прокси разных секций к тестовому серверу.
- Отдельный DNS resolver можно использовать вместе с портами и TCP/UDP. DNS применяется к доменам и доступным признакам устройства/входа независимо от портов будущих соединений; портовые ограничения действуют на соединения. Это поведение объяснено в форме.
- Режим max_active_nodes=0 снимает числовой предел активного пула. Прежние режимы и значение по умолчанию сохранены. Конфигурация с 1100 выходами проверена, но не 1100 реальных одновременных соединений.
- Большие графы проверяются без рекурсивного обхода Python.

303 автоматических сценария: Linux / sing-box 1.12.17 — 292 успешно, 11 пропущено; Windows — 288 успешно, 15 пропущено. Chrome: новые настройки и прежние сценарии на настольной/мобильной ширине прошли (RPC заменён моделью). OpenWrt 25.12.0 / sing-box 1.13.21: новые конфигурации, реальные группы, запуск/остановка, 21 синтетическое WAN-событие — один работник и один перезапуск, API доступен после восстановления. Локальная цепочка SOCKS → HTTP → тестовый сервер передала ожидаемый ответ.

Полное превосходство по каждому параметру не подтверждено: физическая скорость, RAM, длительная стабильность, внешние многоступенчатые/UOT соединения и все архитектуры требуют отдельных испытаний. Ограничения архива подписок, RPC и резервной копии 16 МиБ остаются. Подробности: docs/release-0.26.md в архиве.

IPK для OpenWrt 24.10 / opkg, APK для OpenWrt с apk. APK собран официальным apk-tools из SDK; публичной подписи репозитория нет. Установщик проверяет SHA256 и использует allow-untrusted для пакета Atlas. GitHub Releases и raw-зеркало принадлежат одному провайдеру.
