# Atlas для OpenWrt 24.10.1+

[Atlas 0.28 beta — готовые пакеты, исходники и проверки](https://github.com/Nissanstels1/Atlas/releases/tag/v0.28.0-beta)

Добавлены упорядоченные резервные серверы, импорт xhttp/splithttp, фоновые замеры и проверка передачи 64 КиБ перед выбором по критериям Atlas. Проверены TLS, обрыв передачи, настоящий выбор резерва через локальный API и возврат к основному серверу. Полный финальный Linux-набор: 350 тестов без ошибок и пропусков; браузерные проверки прошли.

Основной пакет: IPK для OpenWrt с opkg, APK для OpenWrt с apk. Дополнительный Atlas Engine r3 нужен для расширенных функций; готовые пакеты движка предназначены только для x86_64. После обновления примените настройки или перезапустите Atlas. APK не подписаны доверенным публичным ключом; SHA256 подтверждает целостность, но не заменяет подпись.

В выпуске доступны полный комплект x86_64, отдельные пакеты, исходники приложения и соответствующие исходники движка GPL-3.0-or-later с зависимостями, лицензиями и рецептом сборки. Исходники приложения также доступны в [atlas-openwrt](atlas-openwrt).

[Описание выпуска и ограничения](atlas-openwrt/docs/release-0.28.md). Превосходство над Podkop по всем параметрам не доказано: физические ARM/MIPS-роутеры, длительная нагрузка, внешний XHTTP-сервер и новая оценка RAM/CPU требуют испытаний. Общей квоты базы пока нет; прежние UDP-повторы не устранены этим выпуском.

Публикация восстанавливает локально проверенный комплект из частей в releases/atlas-0.28, проверяет контрольные суммы, размещает исходники и загружает GitHub Release. Части служат только для доставки комплекта; для установки скачивайте готовые файлы из Releases.
