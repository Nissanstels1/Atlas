# Atlas for OpenWrt 24.10.1+

[Atlas 0.23 beta — packages and source](https://github.com/Nissanstels1/Atlas/releases/tag/v0.23.0-beta)

Закрыты пять недостатков повторного аудита 0.22:

- Разрешение реального IP отдельно для секции: наследовать, включить или выключить; также для назначенных списков и отдельного HTTP/SOCKS входа.
- Собственные URL, интервал и tolerance у обычных proxy-секций с независимыми selector/URLTest, ручным выбором и возвратом в Авто. Общие фильтры и ограничения страны сохраняются. Экспертный JSON управляет своими URLTest самостоятельно.
- Восстановление по событию ifup с задержкой 0–60000 мс (2000 по умолчанию), объединением устаревших событий и ограничением частоты перезапусков; минутный планировщик остаётся резервным.
- Предел команды ручного и автоматического перезапуска 90 секунд; успех автоматического восстановления подтверждается ответом API движка.
- Запуск из интерфейса без профилей для JSON-only и direct/block/exclude секций. Отсутствующий основной proxy остаётся блокирующим. Явно прямые/блокирующие конфигурации получают рабочий прямой DNS; конфигурации с отсутствующим требуемым proxy не получают скрытый DNS fallback.

Дополнительно: импорт UTF-8 файлов из браузера до 4 МиБ вместо 64 КиБ, проверка размера на клиенте, после декодирования и на уровне RPC.

Сохранены полные JSON ruleset без упрощения logical AND/OR, regex, ports и invert, проверка установленным sing-box перед заменой, восстановление файлов из резервной копии, три попытки временных ошибок загрузки, регулируемый размер списков и разрешения частных адресов/symlink.

Проверено 286 автоматических сценариев: Linux с sing-box 1.12.17 — 275 успешно, 11 пропущено; Windows — 271 успешно, 15 пропущено. Chrome: новые настройки, большие файлы, JSON-only запуск, прежние сценарии и мобильный макет. В виртуальной OpenWrt 25.12.0 с sing-box 1.13.21 подтверждены независимые группы, секционное resolve, запуск/остановка и восстановление по синтетическому ifup при выключенном cron, с ответом API после восстановления. Это не испытание физического обрыва провайдера.

Полное превосходство по всем параметрам не заявляется: пропускная способность, RAM и длительная стабильность на одинаковом физическом роутере не измерены. Сохраняются пределы RPC, резервной копии 16 МиБ и удалённых профилей; внешний detour между секциями и DNS resolver с ограничением по портам/транспорту остаются ограничены моделью Atlas. Возможности протоколов и JSON определяет установленный sing-box.

IPK предназначен для opkg, APK — для apk. APK не подписан публичным ключом; ознакомьтесь с контрольными суммами и инструкцией установки. GitHub Releases и raw.githubusercontent.com используют одного провайдера.
