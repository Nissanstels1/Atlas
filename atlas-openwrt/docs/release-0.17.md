# Atlas 0.17: закрытие функциональных пробелов

Целевая платформа — OpenWrt 24.10.1 и новее. Это бета-версия.

## Реализовано

| Пробел аудита 0.16 | Реализация 0.17 |
|---|---|
| Списки для независимой секции | Назначение списка конкретной включённой proxy/VPN/direct-секции по постоянному ID |
| Секция загрузки списков | Выбор секции для сетевого получения списков, включая независимый JSON-прокси и VPN-интерфейс |
| Ручное переключение | Дашборд selector секций, проверка принадлежности узла, сохранение выбора после перезапуска |
| Проверка URLTest секции | Отдельный запуск измерений и ручной выбор для корневого URLTest через управляющий selector; возврат к автоматическому выбору |
| YACD | Встроенная оригинальная MIT-панель; включаемый API с секретом и отдельным разрешением WAN-привязки |
| Bootstrap DNS UDP | Настройка UDP bootstrap в LuCI; глобальный UDP DNS уже существовал в 0.16 — строка предыдущего аудита была неточной |
| Локальные списки | file:// списки из /etc/atlas/lists, /tmp/atlas/lists, /mnt и /media, отслеживание изменения раз в минуту и сохранение последней успешной версии |
| Внешнее хранение | Конфигурация на смонтированном /mnt или /media, проверка пути и запрет символьных ссылок |
| Масштаб | До 256 секций вместо 50 |
| Установка из зеркала | Установщик проверяет manifest/SHA256, выбирает IPK/APK и поддерживает комплект зависимостей; адрес зеркала задаёт администратор |

Общие пулы остаются общими: изменение их selector влияет на использующие их секции. Это явно показано в интерфейсе. Файловые пути ограничены указанными каталогами, размер списка — 4 МиБ. Секции без правил разрешены для графов, списков, загрузки и mixed-входов; они не создают неявное правило для всего трафика.

## Проверки

На Windows прошли 222 из 234 тестов; 12 платформенных проверок пропущены. Отдельные реальные проверки sing-box 1.12.17 и 1.14.2 подтверждают переключение независимой секции и маршрута загрузки списков. Браузерные проверки новых форм используют подменённый RPC и не заменяют установку на OpenWrt.

В изолированной Ubuntu 24.04 прошли 225 из 234 тестов (9 пропущены). Получен нативный APK инструментом apk-tools 3.0.2 из официального OpenWrt SDK 25.12.0: tools/build-apk.py упаковывает архитектурно независимые файлы, зависимости устанавливаются из OpenWrt feeds. Это не результат полной пересборки зависимостей командой make.

На виртуальной OpenWrt 25.12.0 x86_64 с sing-box 1.13.21 успешно установлены зависимости и APK; настоящий RPC возвращает версию 0.17.0. Прошли реальные проверки переключения маршрута списка/загрузки и изоляции двух авторизованных прокси-входов. Системная служба procd создаёт TUN-интерфейс, сохраняет выбор selector и останавливается. APK не подписан доверенным ключом; установка требует явного --allow-untrusted. Размещённого публичного зеркала пока нет.

Стандартному тестовому образу с корневым разделом около 104 МиБ не хватило места для зависимостей. На увеличенном разделе 485 МиБ установка успешна; установленный набор пакетов в этой системе занимает около 93 МиБ. Это не замер дополнительного размера Atlas на любом роутере. Физическое устройство, реальная LAN/WAN, DHCP и аварийные сетевые сценарии не проверены. IPK для ветки 24.10 собран, но установка именно этой версии на 24.10 в текущем прогоне не испытана.

## Границы сравнения

При перезапуске службы восстановлен ручной выбор selector. Встроенная YACD отдаётся через /ui/; запрос API без ключа отклонён кодом 401. Остановка является фоновой операцией: результат следует ждать по статусу задания, а не фиксированной задержке.

Дополнительные функции Atlas: менеджер нескольких подписок, фильтры и приоритеты стран, несколько стратегий выбора узлов, редактируемые локальные профили, резервное копирование и диагностическая выгрузка. Наличие этих функций не доказывает превосходство по скорости, памяти или стабильности. Сравнительных аппаратных измерений с Podkop нет. Проверка на x86 не подтверждает все архитектуры и физические роутеры.

Источники сравнения: [секции Podkop](https://podkop.net/docs/sections/), [настройки](https://podkop.net/docs/settings/), [дашборд](https://podkop.net/docs/dashboard/), [установка](https://podkop.net/docs/install/).
