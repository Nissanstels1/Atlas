# Atlas 0.27.2 beta / Atlas Engine 1.13.21-r2

Исправлена причина остановки регулярных замеров при выборе сервера по критериям Atlas. Такой выбор направляет трафик через конкретный узел, поэтому группа URLTest не получает обращений, запускающих её периодический таймер. Старые замеры со временем теряли свежесть, и Atlas блокировал группу, даже если серверы продолжали работать.

В дополнительный Atlas Engine добавлен явно включаемый параметр URLTest `background` и возможность `urltest.background`. Для таких групп таймер запускается вместе с движком и продолжает работать после срока простоя. Atlas автоматически включает его для управляемых групп с нестандартными критериями выбора: общего пула, подписок и частных секций. Для вручную выбранных групп он не включается. Экспертные группы не изменяются. Стандартное поведение URLTest сохраняется, когда параметр выключен.

Используется существующий таймер и механизм измерений движка. Дополнительный демон, файл истории и отдельная база не создаются. Сохраняются заданные интервалы и штатное ограничение параллельности раунда URLTest. Постоянные фоновые замеры создают регулярный проверочный трафик; снижение расхода CPU или RAM этим выпуском не заявляется.

## Проверки

- Linux: 340 тестов без ошибок и пропусков, включая штатный sing-box 1.12.17 и Atlas Engine 1.13.21-r2.
- Настоящий Atlas Engine, контролируемые локальные HTTP-прокси: группа без входящих соединений и без запросов принудительного тестирования. При выключенном `background` время замера не меняется. При включённом режиме оно обновляется после `idle_timeout`; отключение основного сервера приводит к выбору резерва по критериям Atlas, восстановление — к возврату основного.
- Проверены активация только для управляемых автоматических групп, отключение для ручного выбора и отсутствие нового параметра в конфигурации штатного движка.
- Windows-проверка промежуточной сборки: 321 успешная проверка, 19 требуют Linux или дополнительный Linux-движок. Окончательная полная проверка выполнена на Linux.
- Chrome: формы desktop/mobile и сохранение параметров; обращения к роутеру моделируются.

Это контролируемая проверка таймера, измерений и решений функции выбора Atlas. Переключение пользовательского трафика в этом сценарии не испытывается. Это не многосуточный тест физического роутера или новый нагрузочный замер памяти.

## Установка

Для opkg: `luci-app-atlas_0.27.2-1_all.ipk` и `atlas-engine_1.13.21-2_x86_64.ipk`. Для apk: `luci-app-atlas-0.27.2-r1.apk` и `atlas-engine-1.13.21-r2.apk`. После обновления движка примените настройки или перезапустите Atlas. Движок устанавливается рядом со штатным sing-box и не создаёт второй службы.

Готовые пакеты движка предназначены для x86_64. APK локальные и не подписаны доверенным публичным ключом. Комплект содержит соответствующие исходники GPL-3.0-or-later, vendored-зависимости, 86 исходных патчей FiyeroT/podkop-engine v1.13.21-r12, отдельный патч Atlas, лицензии, рецепт сборки и контрольные суммы. Сборка использует Go 1.26.8, CGO выключен; TUN сохранён.

Штатному sing-box и Atlas Engine r1 параметр `background` не отправляется. Для них ограничение регулярных замеров без обращений к самой группе сохраняется; интерфейс сообщает необходимость нового движка.

## Что остаётся

Проверка скачивания 64 КиБ по собственному URL пока несовместима с дополнительными критериями выбора Atlas; неподдерживаемое сочетание отклоняется явно. Физические ARM/MIPS-роутеры, внешний XHTTP-сервер, точная OpenWrt 24.10.1 и длительная нагрузка здесь не проверялись. Квоты общего размера базы пока нет. Причина двух повторов UDP-запросов на предыдущем стенде не устранена этим изменением. Результаты RAM/кэша версии 0.27.0 не считаются измерениями 0.27.2. Превосходство по всем показателям над Podkop не доказано.

Выпуск подготовлен локально; GitHub не обновлялся. Предыдущие результаты: [0.27.0](release-0.27.md), [0.27.1](release-0.27.1.md).
