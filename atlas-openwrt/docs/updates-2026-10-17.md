# Обновления Atlas от 17 октября 2026 года

Обновлён установщик по одной ссылке: он устанавливает базовые пакеты Atlas 0.29.0 и автоматически накладывает проверенные исправления из закреплённого коммита. Проверяются SHA-256 самого исправления и каждого заменяемого файла. Дополнительную команду исправления выполнять не нужно. Выполните основную команду установки повторно, чтобы обновить существующую установку; настройки сохраняются. Это запуск обновления пользователем, а не фоновая служба автообновления.

## Профили и фильтры

По умолчанию таблица показывает только профили, прошедшие общие фильтры. Выделенная плашка сообщает число разрешённых и скрытых профилей. «Показать все профили» временно открывает исключённые записи для просмотра; ограничения автовыбора сохраняются. Поиск и страницы учитывают выбранный режим. При пустом разрешённом пуле выводится объяснение, без автоматического перехода на запрещённые профили или прямой маршрут.

«Исключить по названию» принимает несколько фрагментов через запятую: LTE, RUS. Совпадение с любым фрагментом исключает профиль. Регистр не учитывается; это поиск части названия, без исправления опечаток, перевода и регулярных выражений. Общие фильтры действуют на подписочные пулы секций; собственные экспертные JSON-выходы настраиваются отдельно.

## DNS, производительность и монитор

- FakeIP используется только для A/AAAA. HTTPS/SVCB-запросы проксируемых доменов получают пустой успешный ответ, остальные типы сохраняют соответствующий защищённый DNS-маршрут. Устранены повторы из-за попытки запросить неподдерживаемый тип у FakeIP.
- Повторные обращения к локальному API используют одну разобранную конфигурацию в пределах процесса. Содержимое проверяется по SHA-256: изменение, повреждение или удаление файла не маскируется старым кешем. Хранится одна версия без накопления истории.
- Монитор читает память самого движка с проверкой владения процессом и повторного использования PID, включая OpenWrt без файла children. Расход управляющего Python-процесса больше не выдаётся за расход движка.

В изолированном сравнении на 1200 синтетических профилях десять внутренних вызовов потребовали один разбор JSON вместо десяти; этот участок ускорился в 2,49 раза. Это не измерение скорости интернета, запуска видео или работы всех профилей в сети.

## Проверки и пределы

Окончательная серверная версия прошла 507 тестов на отдельной виртуальной OpenWrt: ошибок нет, один тест образа диска пропущен из-за отсутствия e2fsprogs. Проверены 84 представления и 12 диалогов в браузере на ширине 320–1440 пикселей. На демонстрационных данных проверены исключения, поиск, страницы, показ всех и обновление статуса. Результат отдельной проверки публичной установки указан в README после её завершения.

Производительность зависит от провайдера, прокси-серверов и локальной сети. Долгая ручная HTTPS-проверка по-прежнему может задерживать расширенный планировщик выбора; обычные фоновые замеры движка продолжаются. Полная анонимность и универсальное превосходство над Podkop не заявляются.
