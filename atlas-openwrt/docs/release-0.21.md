# Atlas 0.21.0 beta

Закрыты ограничения источников списков, отмеченные в версии 0.20:

- Для каждого списка можно разрешить частные адреса: IP, короткие имена серверов и домены .lan/.local. Разрешение распространяется на перенаправления HTTP; переход с HTTPS на HTTP по-прежнему отклоняется.
- Для каждого локального списка можно разрешить символьные ссылки на файл или каталог. Конечный файл проверяется на существование, тип, размер и содержимое. Изменения целевого файла учитываются планировщиком обновлений.
- Разрешения доступны в форме маршрутизации, сохраняются в резервной копии и не теряются при сохранении общих настроек или обращении старого клиента.

Добавлен tools/benchmark-router.py для повторяемых измерений генерации конфигурации и проверки движком на самом устройстве. Он читает сохранённое состояние без изменения службы и не выводит содержимое конфигурации или секреты. Пример: python3 benchmark-router.py --iterations 100 --engine /usr/bin/sing-box > atlas-benchmark.json.

Инструмент не измеряет пропускную способность пакетов, задержку DNS, утечки памяти или длительную стабильность службы. Эти параметры и сравнение с Podkop требуют испытаний на одинаковом физическом оборудовании. Данная версия не заявляет доказанного превосходства по всем параметрам.

Проверки: Windows — 248 успешных и 15 пропущенных; Linux — 252 успешных и 11 пропущенных. В Linux проверены настоящие символьные ссылки на файл и каталог, изменение цели, битая ссылка. Проверка интерфейса в Chrome прошла с имитацией RPC роутера. В Linux-виртуальной среде конфигурация со 100 секциями прошла 20 проверок sing-box 1.12.17 без ошибок; генерация детерминирована. Эти результаты не являются сравнительным испытанием скорости с Podkop.
