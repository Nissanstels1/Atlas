# Atlas 0.28.0 beta / Atlas Engine 1.13.21-r3

Проверка скачивания 64 КиБ теперь совместима с приоритетом стран, порогами пинга и стратегиями выбора Atlas. Перед переключением выбранный сервер проходит HTTPS-проверку передачи через собственный выход уже работающего движка. Временный прокси-процесс не запускается. Основной сервер с подходящим пингом, но оборванной передачей пропускается; Atlas проверяет следующего кандидата, затем резервы в установленном порядке. Без успешной проверки группа блокируется.

Новый API движка `clash.download_test` требует авторизации существующим секретом локального API. Проверяется конкретный выход; группы и direct/block/DNS не допускаются. Требуются HTTPS, корректный сертификат и имя сервера. Перенаправления не выполняются, сжатие выключено, читается не более 65536 байт без сохранения тела. Запрос имеет предел 1–5 секунд; одновременно допускаются не более двух проверок, без очереди.

За один цикл Atlas выполняет максимум четыре запроса проверки. При исчерпании бюджета непроверенный кандидат не выбирается. Порядок обработки групп сдвигается между циклами, чтобы первые неисправные группы не занимали бюджет постоянно. Успешная проверка неизменившегося выбранного узла может повторно использоваться до пяти минут; любое переключение требует новой проверки. Смена конфигурации/запуска, изменение URL и истечение срока отменяют повторное использование. После передачи повторно проверяется свежесть исходного замера.

Подтверждения хранятся в `/var/run/atlas/download-proofs.json`: только хеши и время, без URL, имён, паролей или тела ответа. Ограничение — 4096 записей; слишком большой или повреждённый файл не используется. Это ограниченный временный файл, не новый namespace базы FakeIP. База FakeIP по-прежнему не имеет общей квоты.

Сохраняются фоновые замеры Atlas Engine r2 и упорядоченные резервы 0.27.1. Проверка возможностей предотвращает применение новой функции со старым движком. Установщик пропускает пакет дополнительного движка x86_64 на других архитектурах; основной пакет остаётся архитектурно независимым.

## Проверки

- Полный Linux-набор: 350 тестов без ошибок и пропусков; штатный sing-box 1.12.17 и Atlas Engine 1.13.21-r3.
- Реальный движок и локальные HTTPS-прокси: обрыв после 16384 байт отклонён; резерв передал 65536 байт до настоящего переключения селектора через API Atlas. Проверены отказ при неправильном имени сертификата, запрет HTTP и групп, ограничение времени зависшей передачи.
- Проверены срок, привязка к конфигурации/URL, повторное использование только при неизменившемся выборе, общий бюджет попыток, предел количества записей и запрет выбора при истечении свежести замера во время передачи.
- Фоновые замеры без трафика через URLTest и возврат к основному серверу проверены настоящим движком.
- Установщик: x86_64, aarch64 и mips для обоих форматов пакетов проверены на уровне фактического фильтра списка пакетов; это не аппаратные испытания ARM/MIPS.
- Chrome: формы desktop/mobile и сохранение настроек; обращения к роутеру моделируются. Windows-проверка промежуточной сборки: 328 успешных, 20 требуют Linux/дополнительного движка. Окончательная полная проверка — на Linux.

## Установка

Для opkg: `luci-app-atlas_0.28.0-1_all.ipk` и, на x86_64, `atlas-engine_1.13.21-3_x86_64.ipk`. Для apk: `luci-app-atlas-0.28.0-r1.apk` и `atlas-engine-1.13.21-r3.apk`. После установки движка примените настройки или перезапустите Atlas. Дополнительный движок сохраняет TUN, устанавливается рядом со штатным sing-box и не создаёт второй службы.

Комплект содержит исходники приложения и соответствующие исходники движка GPL-3.0-or-later, vendored-зависимости, 86 исходных патчей FiyeroT/podkop-engine v1.13.21-r12, два дополнительных патча Atlas, лицензии и рецепт сборки. Go 1.26.8, CGO выключен. Готовый движок предназначен только для Linux/OpenWrt x86_64; APK не подписаны доверенным публичным ключом. SHA256 проверяет целостность файлов и не заменяет независимую подпись.

## Ограничения

Перед переключением нужен работоспособный выбранный HTTPS-файл длиной не менее 64 КиБ. Короткий файл, TLS-ошибка, иной HTTP-статус и любой обрыв приводят к отказу проверки; отсутствие проверки не считается успехом. Это более строгий режим, который может блокировать рабочий узел при неисправности самого проверочного сайта. При большом количестве групп их проверка распределяется по циклам; мгновенная проверка всех узлов не обещается.

Физические ARM/MIPS-роутеры, точная OpenWrt 24.10.1, внешний XHTTP-сервер и многосуточная нагрузка здесь не испытывались. Новых измерений RAM/CPU/кэша этой версии нет. Причина двух повторов UDP-запросов в тесте 0.27.0 не устранена этим изменением. Полное превосходство над Podkop по скорости, расходу ресурсов и всем параметрам не подтверждено. Предыдущие нагрузочные данные относятся к [версии 0.27.0](release-0.27.md).
