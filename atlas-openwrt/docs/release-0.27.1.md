# Atlas 0.27.1 beta

Снято ограничение версии 0.27.0: упорядоченные резервные серверы теперь совместимы с приоритетом стран, стратегиями скорости/стабильности и порогами пинга Atlas.

Основные серверы оцениваются первыми. Если ни один не подходит по свежим замерам и заданным критериям, выбирается первый подходящий резерв в установленном порядке. Более быстрый резерв не вытесняет подходящий основной сервер. После восстановления подходящего основного узла Atlas возвращается к нему. Если подходящих свежих замеров нет, группа блокируется; прямой выход не подставляется.

Отдельные секции используют собственные резервные списки. Для секций UDP-over-TCP резервные ID переводятся в частные имена этой секции. Порядок общего пула не изменяет порядок секции. Поиск позиции резерва использует таблицу ID, без повторного обхода полного списка для каждого узла. Новая функция не создаёт постоянного кэша, новых файлов истории или дополнительных процессов.

## Проверки

- Linux: 337 тестов, без ошибок и пропусков, sing-box 1.12.17 и дополнительный Atlas Engine 1.13.21-r1.
- Реальный Atlas Engine принимает конфигурацию с резервами после преобразования имён при запуске; Auto в управляемом селекторе остаётся командой защищённого выбора, а не обходом критериев.
- Проверены порядок резервов, возврат к основному, запрет устаревших/неподходящих измерений и независимый резерв частной секции.
- Chrome: интерфейс desktop/mobile и сохранение настроек; обращения к роутеру моделируются.
- Проверки Windows на промежуточной версии изменений: 319 успешных, 17 Linux-проверок пропущены. Окончательная полная проверка выполнена на Linux.

## Установка и оставшиеся ограничения

Для OpenWrt с opkg используется `luci-app-atlas_0.27.1-1_all.ipk`, с apk — `luci-app-atlas-0.27.1-r1.apk`. Расширения резервов требуют ранее собранного Atlas Engine 1.13.21-r1. Его пакеты и исходники включены в комплект; готовые бинарные пакеты дополнительного движка предназначены только для x86_64. APK не подписаны доверенным публичным ключом.

Проверка скачивания 64 КиБ по собственному URL пока требует нативного режима «Самый быстрый» без дополнительных критериев Atlas. Такое сочетание явно отклоняется, чтобы не заявлять проверку передачи, которой защищённый выбор не выполняет. Резервные узлы остаются под ограничениями фильтров и активного пула; требуется хотя бы один основной узел.

Выбор по критериям требует свежих измерений движка. Длительное обновление измерений групп, которые не получают трафик через сам URLTest, требует отдельной проверки и доработки; при исчезновении свежих замеров Atlas блокирует группу. Этот выпуск не заявляет устранение этого ограничения.

Нагрузочные результаты 0.27.0 (кэш 256 КиБ на повторных доменах, RSS 29.02–29.56 МиБ, два повтора в UDP-тесте) относятся к предыдущему выпуску. Для 0.27.1 эти сценарии повторно не выполнялись. Не доказаны отсутствие утечек при многосуточной работе, поддержка ARM/MIPS, работа с внешним XHTTP-сервером и превосходство по всем показателям над Podkop. Полной квоты размера базы пока нет. Предыдущие результаты и происхождение движка описаны в [отчёте 0.27.0](release-0.27.md).

Выпуск подготовлен локально; GitHub не обновлялся.
