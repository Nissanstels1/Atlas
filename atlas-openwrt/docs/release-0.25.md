# Atlas 0.25 beta

Исправлены три недостатка повторного аудита 0.24:

- Расширенный автовыбор оценивает свежесть замеров по собственному интервалу секции. При общем интервале 60 секунд и секционном 300 замер возрастом 200 секунд больше не вызывает ошибочную блокировку. Обратный случай также проверен: короткий интервал секции не позволяет использовать устаревший замер из-за длинного общего интервала. Фильтры и остальные критерии сохраняются.
- Ошибка переключения одной группы не останавливает обработку остальных. Результат содержит последний известный выбранный выход, запрошенный выход и признак ошибки для неудачной группы; успешные операции сохраняются. Итог partial-failure записывается в диагностику. При невозможности получить общий список прокси по-прежнему возвращается controller-unavailable.
- Проверка задержек секции обходит полный набор выходов без усечения списка на 1024 элементах. Группы и блокирующий выход больше не занимают места в лимите, из-за которого два последних сервера максимального пула не проверялись. Один недоступный выход не мешает проверять следующие. Проверки выполняются последовательно; большой пул с недоступными серверами может занимать значительное время.

Три воспроизводимых сценария добавлены в tests/test_selection_recheck.py. Проверка 1024 серверов использует модель ответов контроллера, не 1024 реальных сетевых соединения.

Выпуск включает IPK для OpenWrt 24.10 / opkg и APK для OpenWrt с apk. APK собран официальным apk-tools из SDK; публичной подписи репозитория нет, установщик проверяет SHA256 и использует allow-untrusted для пакета Atlas.

Физическая скорость, RAM и длительная сравнительная стабильность с Podkop ещё не измерены. Ограничения резервной копии 16 МиБ, RPC, удалённых профилей и detour между независимыми секциями сохраняются. Полное превосходство по всем параметрам не заявляется.

297 автоматических сценариев: Windows с sing-box 1.12.17 — 282 успешно, 15 пропущено; Linux с sing-box 1.12.17 — 286 успешно, 11 пропущено. В OpenWrt 25.12.0 / sing-box 1.13.21 повторены три исправленных сценария с моделью контроллера и реальная проверка конфигурации, независимых групп, запуска/остановки, восстановления WAN: 21 синтетическое событие, один работник и один перезапуск, API движка доступен. Это не испытание физического обрыва провайдера. Повторение: tests/native_selection_025.py и tests/native_sections_025.py.
