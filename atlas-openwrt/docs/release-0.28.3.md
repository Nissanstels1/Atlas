# Atlas 0.28.3 — свежесть доказательств и замеров

Исправления:

- Срок HTTPS-подтверждения повторно проверяется в момент использования, включая время, потраченное на другие группы. Для течения времени внутри цикла используются монотонные часы.
- Ответ скачивания после общего срока цикла не допускает переключения и не сохраняется как успешный. Таймаут сетевого запроса остаётся отдельным ограничением; общий срок не прерывает уже выполняющийся вызов мгновенно.
- Успешное подтверждение получает время завершения, а просроченные записи исключаются при экспорте.
- Последний URLTest-замер должен быть свежим и иметь корректное время с часовым поясом. Повреждённый или устаревший последний замер не заменяется более старым успешным замером. Смещения RFC3339 учитываются.

Проверены логика резервов, отсутствие кандидатов, неудачная передача, запрет восстановления старого выбора, бюджет запросов, границы срока, настройка независимых секций и обработка ошибок переключения. Ошибка API по-прежнему не считается успешной блокировкой трафика.

5000 последовательных циклов контроллера подтверждений: число сохранённых записей стабильно 300 при одном новом узле в секунду и сроке 300 секунд. Измерение Python-выделений относится только к контроллеру, включая тестовые структуры; не является измерением RSS движка или NanoPi. Отчёт поставляется отдельно.

Сохраняются ограничения: нет общей квоты FakeIP, физических ARM64 и многосуточных нагрузочных испытаний, гарантии нулевых утечек или отсутствия любых ошибок. При отключении лимита списка возможен повышенный расход памяти. Прошедшие управляемые тесты не доказывают работу всех внешних провайдеров.

Итоговая проверка Linux: 358 тестов без ошибок и пропусков со штатным sing-box 1.12.17 и Atlas Engine r3. Контролируемые HTTPS-проверки и фоновое восстановление проверены настоящим движком. Windows: 338 успешных, 20 Linux-зависимых пропущены. Chrome desktop/mobile и DOM-тест объединения запросов прошли; обращения к роутеру моделируются.

## Установка одной командой

В терминале OpenWrt под root:

```sh
wget -O /tmp/atlas-install.sh https://raw.githubusercontent.com/Nissanstels1/Atlas/main/install.sh && sh /tmp/atlas-install.sh
```

Установщик привязан к выпуску v0.28.3-beta, проверяет SHA256 установщика и пакетов, выбирает ARM64/x86_64, устанавливает LuCI и зависимости из настроенных OpenWrt feeds. Для NanoPi R4SE с opkg дополнительно проверяется aarch64_generic в списке архитектур прошивки. Приложение находится в LuCI → Службы → Atlas. Добавление подписки и включение маршрутизации выполняются в интерфейсе. Настройки существующего Atlas сохраняются; отдельная upgrade-backup создаётся до установки. Автоматическая установка не удаляет Podkop и другие конфликтующие службы.

Для opkg используются IPK, для apk — APK с явным allow-untrusted в bootstrap, поскольку публичной подписи APK нет. SHA256 не заменяет независимую подпись. TLS-проверка скачивания не отключается. Сборки движка готовы для ARM64 и x86_64; ARM64 на физическом роутере ещё не испытывался. Требуются интернет-доступ к GitHub и исправные feeds именно установленной прошивки, особенно для kmod-tun.

Установщик проверен в изолированной модели: ARM64/x86_64, opkg/apk, отказ до установки при неверной контрольной сумме и несовместимой opkg-архитектуре. Эти проверки не являются запуском на физическом NanoPi.
