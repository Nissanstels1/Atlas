# Atlas 0.22.0 beta

Доработки по результатам функциональной сверки Podkop 0.7.22:

- Полные JSON ruleset: сохраняются domain, domain_regex, port, logical AND/OR, invert и другие поля, которые принимает установленный sing-box. Перед заменой списка исходный JSON компилируется движком и проверяется итоговая конфигурация. Невалидная версия не заменяет рабочую. Поддержаны URL, file:/// и импорт JSON из файла в интерфейсе; auto распознаёт JSON по содержимому.
- JSON ruleset включён в резервную копию без упрощения логики. При восстановлении движок повторно проверяет JSON; сохранённый адрес и содержание скрыты в публичном статусе.
- До трёх попыток загрузки при временных HTTP-ошибках 408/429/5xx и сетевых ошибках, с паузой 2 секунды. Общий бюджет загрузки 90 секунд. Постоянные ошибки 4xx, ошибки формата и превышение размера не повторяются. Маршрут через выбранный прокси сохраняется во всех попытках.
- Сняты отдельные лимиты 64 источника, 10 000 записей на список, 50 000 суммарных записей и 8 входных/контролируемых интерфейсов. Реальные пределы определяются памятью, движком и размером запросов RPC.
- Сняты ограничения 1000 записей ручных/секционных списков и 64 объекта/128 КиБ администраторского JSON-графа. Ограничения импортируемых удалённых профилей и размеров RPC/резервной копии остаются отдельными.
- Размер файла списка задаётся в интерфейсе: 4 МиБ по умолчанию, от 1 до 256 МиБ либо 0 без ограничения размера. Ограничения подписок на серверы не изменены. Большой список может потребовать много памяти.
- URL с fragment принимается; fragment не отправляется HTTP-серверу. Абсолютные локальные пути с ../ поддерживаются. Разрешения частных адресов и символьных ссылок сохранены.
- Исправлен старый номер версии в статусе и диагностическом отчёте. JSON можно импортировать до добавления прокси-профилей: отсутствующий основной прокси остаётся блокирующим, без прямого fallback.
- Допустимое время команды запуска службы увеличено до 90 секунд для медленных систем. Это не задержка успешного запуска. При истечении времени восстанавливается прежняя конфигурация и возвращается понятное сообщение.

Полный функциональный паритет всех сочетаний настроек и превосходство по всем параметрам не заявляются. Скорость сетевого трафика, RAM, длительная стабильность и реальный IPv6 требуют сравнения с Podkop на одинаковом физическом оборудовании. Тест виртуальной OpenWrt не заменяет эти измерения.

Проверки выпуска: 271 автоматическая проверка в Linux с sing-box 1.12.17 — 260 успешно, 11 пропущено по условиям среды. В Windows — 256 успешно, 15 пропущено. Проверка интерфейса в Chrome прошла, включая мобильную ширину, импорт JSON и сохранение настроек.

В виртуальной OpenWrt 25.12.0 с sing-box 1.13.21 подтверждены импорт JSON до добавления прокси, три реальные HTTP-попытки, проверка конфигурации движком, восстановление удалённых файлов из резервной копии, запуск и остановка службы. Отдельный пакетный тест проверяет IPv4 и IPv6 с одинаковыми адресами клиентов на двух входных интерфейсах и сопоставляет каждое соединение с правильным исходящим маршрутом. Доставка пакетов в интернет и физическая производительность этим тестом не измеряются. Фоновый планировщик в изолированных испытаниях временно остановлен, затем восстановлен.
