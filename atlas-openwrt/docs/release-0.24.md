# Atlas 0.24 beta

Исправлены пять недостатков повторного аудита 0.23:

- Пустой пул подписки при включённых удалённых списках даёт понятную ошибку конфигурации вместо KeyError. Отсутствующий прокси не заменяется прямым выходом.
- Экспертный URLTest может содержать узел с тегом control. Автоматически создаваемый selector получает свободный тег; исходные связи графа сохраняются.
- Восстановление WAN, планировщик и пользовательские операции используют общую блокировку. Два запроса восстановления одного события не перезапускают движок дважды.
- Серия событий WAN обновляет одну очередь и обслуживается одним ожидающим обработчиком. Блокировка передаётся дочернему процессу ещё при запуске, поэтому нет окна для создания нескольких работников. Новое событие продлевает ожидание; выход обработчика согласован с записью событий. Сохраняются ограничение перезапусков и резервная обработка планировщиком.
- UDP-over-TCP задаётся отдельно для обычной прокси-секции: наследовать, включить или выключить; версия 1/2 также может наследоваться. Для SOCKS и Shadowsocks создаются отдельные копии выходов, поэтому секции одного пула могут иметь противоположные настройки. Ручной выбор, автовыбор, имена серверов и фильтры сохраняются. Экспертный JSON задаёт этот параметр самостоятельно. Сервер должен поддерживать выбранную версию.

Старые клиенты сохраняют заданные ранее секционные параметры UDP-over-TCP. Новые поля входят в обычное состояние и резервную копию.

294 автоматических сценария: Windows с sing-box 1.12.17 — 279 успешно, 15 пропущено; Linux с sing-box 1.12.17 — 283 успешно, 11 пропущено. Проверки включают конфигурацию с конфликтующим control, пустой пул, одновременное восстановление, ограничение работников, отдельные выходы UDP-over-TCP, ручной и автоматический выбор, сохранение старым клиентом. Chrome проверяет новые поля и прежние сценарии на настольной и мобильной ширине; RPC в этой проверке заменён тестовой моделью.

IPK предназначен для OpenWrt 24.10; APK собран официальным apk-tools из SDK OpenWrt и проверяется в OpenWrt 25.12. APK не подписан ключом публичного репозитория: установщик проверяет SHA256 и использует allow-untrusted для этого пакета.

Всеобщее превосходство над Podkop не подтверждено. Физическая пропускная способность, расход RAM и длительная сравнительная стабильность требуют испытаний на целевом роутере. Сохраняются ограничения резервной копии 16 МиБ, RPC, удалённых профилей и связей detour между независимыми секциями. Возможности протоколов определяет установленный sing-box. GitHub Releases и raw-зеркало относятся к одному провайдеру.

В виртуальной OpenWrt 25.12.0 с sing-box 1.13.21 проверены независимые группы и копии SOCKS с разными параметрами UDP-over-TCP, запуск/остановка и восстановление WAN без cron. Серия из 21 синтетического ifup при дополнительном вызове планировщика имела один обработчик и один перезапуск; обработано последнее событие, API движка доступен. Это проверка координации и конфигурации, не измерение UDP-трафика до внешнего сервера или физического обрыва провайдера. Повторение: tests/native_sections_024.py.
