## Что именно означает тест переключения

Это настоящий сетевой тест с запущенным sing-box, двумя локальными VLESS серверами и намеренной задержкой резервного. Имена EE/DE — тестовые метки, серверы физически не находились в этих странах. Временный сертификат доверен только тестовой VM. В её runtime-конфигурации адрес URLTest заменён на локальный HTTPS endpoint; в исходниках приложения остаётся www.gstatic.com/generate_204. Для проверки передачи данных в тестовую конфигурацию добавлен mixed inbound с явным маршрутом через selector. Полный путь трафика LAN через TUN этим тестом не проверен.

Начальная проверка была вызвана через локальный Clash API. После выключения основного процесса переключение произошло по таймеру URLTest без ручной смены узла. Существующие соединения и возврат на восстановленный основной сервер отдельно не проверялись. Рабочий резерв должен входить в разрешённый фильтрами пул.

## Исправления по результатам установки

1. Архив пакета теперь содержит каталоги до файлов: первая реальная установка прежней версии выявила, что opkg не создавал отсутствующие родительские каталоги.
2. В conffiles указан существующий state.json; добавлен шаблон с правами 0600 и keep.d для сохранения /etc/atlas при sysupgrade. Сам sysupgrade не выполнялся.
3. Остановка ждёт завершения procd до пяти секунд. Прежняя версия могла сообщать ошибку, когда процесс ещё завершался, хотя служба затем останавливалась.
4. Для изолированных проверок узлов включён auto_detect_interface, чтобы исходящие соединения использовали обнаруженный интерфейс при активном TUN. Успешная проверка внешнего EE после этого изменения не подтверждена.
5. Вместо полного Python используются необходимые модули; импорты и операции backend проверены с этим набором зависимостей.

Выпуск остаётся beta. Успешное получение списка серверов, метка страны и запуск службы не доказывают работоспособность реального туннеля.
