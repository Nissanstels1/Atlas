# Повторная функциональная сверка Atlas 0.18 и Podkop 0.7.22

Реестр: **70 пользовательских сценариев**. Atlas: **64 реализовано, 6 частично**. У Podkop **50 найдены** в проверенном встроенном наборе; ещё **20 не найдены**. Это счёт по этому реестру, а не официальное полное количество всех возможных функций.

Совпадающий набор: 44 сценария. Частичное покрытие Atlas: 6. Дополнительный набор Atlas: 20.

Единица счёта — отдельный пользовательский сценарий. Подтипы DNS, отдельные протоколы URI, поля формы и стратегии одной функции не считаются отдельными строками. Наличие произвольного JSON и внешних инструментов может расширять оба приложения; «не найдено» не означает принципиальную невозможность.

Сверены официальный релиз [Podkop 0.7.22](https://github.com/itdoginfo/podkop/tree/0.7.22), [секции](https://podkop.net/docs/sections/), [настройки](https://podkop.net/docs/settings/), [дашборд](https://podkop.net/docs/dashboard/) и [диагностика](https://podkop.net/docs/diagnostics/). Исходники Podkop использованы для проверки, код в Atlas из них не копировался.

## Что добавлено в 0.18

Автозапуск независимо от службы; журнал Atlas; скрывающий секреты предпросмотр; проверка установленным движком без применения; исключения внутри секции; копирование секций; объяснение маршрута; поиск простых доменных перекрытий. Источников списков теперь 64 вместо 16, общий текстовый кеш остаётся 50000 записей.

Нельзя утверждать полное превосходство: шесть строк покрыты лишь частично. Количество функций не доказывает скорость, экономию памяти, зрелость, безопасность или стабильность. Внешние адреса и протоколы проверяются также установленным sing-box.

Машиночитаемая таблица с указателями на реализацию находится в docs/feature-matrix-0.18.json.
