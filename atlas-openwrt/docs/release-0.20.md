# Atlas 0.20.0 beta

Исправлена совместимость источников списков с Podkop 0.7.22:

- HTTP/HTTPS-ссылки поддерживают параметры запроса, включая токены и версии. Загрузчик передаёт исходную ссылку без изменения кодирования.
- Локальные списки принимают нормализованный абсолютный путь без ограничения расширения. Формат определяется выбранным обработчиком и содержимым.
- В статусе сохранённого источника скрыты путь и параметры; схема HTTP/HTTPS отображается правильно. Подсказка интерфейса обновлена.

Проверены 257 сценариев на Windows: 243 успешных, 14 требуют Linux. В Linux: 246 успешных, 11 пропущены из-за требований к роутеру/движку. Браузерная проверка интерфейса успешна, запросы роутера в ней имитируются. APK собран в ранее подготовленной локальной Linux-среде. Контрольные суммы пакетов, CRC архива и соответствие вложенного APK проверены.

Эта версия закрывает два подтверждённых ограничения предыдущего сравнения. Количество функций не доказывает превосходство по каждому параметру. Доступ к частным адресам источников и символьным ссылкам остаётся ограничен. Скорость, длительная стабильность и работа на физическом роутере OpenWrt 24.10.1 требуют отдельных испытаний.
